# 重女判定表 / これって重い？判定シート

[在线填写](https://zerobeyondlogic.github.io/omonna-sheet/)

包含 30 道三选一题和一栏自由填写。支持简体中文与日语、逐题与整表填写、浏览器自动保存，以及结果图和三页判定表的 PNG 导出。结果按三种选项统计。

## 本地运行

使用 Node.js 20 或更新版本运行 `npm start`，然后打开 `http://127.0.0.1:4173/`。也可以直接打开 `public/index.html`。

## 部署

在仓库的 Settings → Pages 选择 GitHub Actions 作为发布来源。提交到 `main` 后，工作流会检查脚本并发布 `public/`。
